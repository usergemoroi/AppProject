## 📊 Что реализовано

### 🎯 Основной функционал (100%)

 **Ежедневное окно загрузки**
- 60-секундное окно для всех пользователей одновременно
- Push-уведомление о запуске бомбы
- Таймер обратного отсчёта
- Ограничение: одна бомба на пользователя в день

 **Загрузка контента**
- Фото из галереи (готово)
- 5-секундное видео (готово)
- Размытие лиц (опционально, manual)
- Компрессия для быстрой загрузки (C++ NDK)
- Анонимность (без имён пользователей)

 **Голосование эмодзи**
- 3 эмодзи: 🔥 (огонь), 💀 (череп), 🤡 (клоун)
- 5-минутное окно голосования
- Один голос на бомбу от пользователя
- Реалтайм подсчёт голосов

 **Топ-10 бомб дня**
- Сортировка по взвешенной формуле:
  - 🔥 = 3 очка
  - 💀 = 2 очка
  - 🤡 = 1 очко
- Реалтайм обновление позиций
- Красивые бейджи для топ-3

 **Гео-фильтры**
- 4 уровня: 10 км / Город / Страна / Глобал
- Firebase Geolocation
- Настройка в профиле

 **Система прогресса**
- Стрики (последовательные дни участия)
- Виртуальные монеты за действия
- Достижения и бонусы
- Статистика в профиле

 **PRO версия**
- UI для покупки (299₽/мес)
- Список преимуществ
- Готово к интеграции Google Play Billing

## 🚀 Как запустить

### Быстрый старт (1 минута)
```bash
# 1. Откройте Android Studio
# 2. File → Open → выберите папку проекта
# 3. Нажмите Run (▶️)
```

### Полная настройка (15 минут)
1. Создайте Firebase проект
2. Скачайте `google-services.json`
3. Замените в `app/google-services.json`
4. Настройте Firestore, Storage, FCM
5. Деплойте Cloud Functions
6. Запустите приложение
