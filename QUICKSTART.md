# 🚀 БомбаДня - Быстрый старт (5 минут)

Минималистичная инструкция для быстрого запуска приложения.

---

## ⚡ Шаг 1: Установите необходимые инструменты (1 мин)

1. **Android Studio:** https://developer.android.com/studio
2. **JDK 17+** (обычно идет с Android Studio)

---

## 📥 Шаг 2: Откройте проект (1 мин)

1. Запустите Android Studio
2. **File → Open**
3. Выберите папку `BombaDay`
4. Дождитесь синхронизации Gradle (2-3 минуты)

---

## 🔥 Шаг 3: Настройте Firebase (2 мин)

### Вариант A: Быстрый (для тестов)

Приложение уже содержит демо `google-services.json`. Просто запустите!

⚠️ **Важно:** Демо конфиг не подключен к реальной базе Firebase.

### Вариант B: Полный (для продакшена)

1. Зайдите на https://console.firebase.google.com/
2. Создайте новый проект
3. Добавьте Android приложение:
   - Package: `com.bombaday.app`
   - Nickname: `BombaDay`
4. Скачайте `google-services.json`
5. Замените файл в папке `app/`

**Важные сервисы для включения:**
- ✅ Firestore Database
- ✅ Firebase Storage
- ✅ Cloud Messaging (FCM)
- ✅ Authentication (Anonymous)

---

## ▶️ Шаг 4: Запустите приложение (1 мин)

### На эмуляторе:

1. **Tools → Device Manager → Create Device**
2. Выберите **Pixel 5** или новее
3. System Image: **API 33** (Android 13)
4. Нажмите **▶️ Run** (Shift+F10)

### На реальном устройстве:

1. Включите **Режим разработчика** на телефоне:
   - Настройки → О телефоне → 7 раз нажмите "Номер сборки"
2. Включите **Отладку по USB**:
   - Настройки → Для разработчиков → Отладка по USB
3. Подключите телефон к компьютеру
4. Нажмите **▶️ Run**

---

2. **Загрузите тестовую бомбу** через приложение

3. **Проголосуйте** эмодзи на своей или чужой бомбе

## ❓ Проблемы?

### "Gradle sync failed"
→ File → Invalidate Caches → Invalidate and Restart

### "SDK not found"
→ File → Project Structure → SDK Location → укажите путь к Android SDK

### "Google services plugin error"
→ Убедитесь что `google-services.json` в папке `app/`

### Приложение падает
→ Проверьте логи: `adb logcat | grep BombaDay`
