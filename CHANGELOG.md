# Changelog

Все значимые изменения в проекте БомбаДня будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] - 2026-02-13

### Добавлено
- ✨ Первый релиз приложения БомбаДня
- 📸 Поддержка загрузки фото и видео (до 5 сек)
- ⏱️ 60-секундное окно для загрузки контента
- 🔥💀🤡 Система голосования с эмодзи реакциями
- 🏆 Топ-10 бомб дня с реалтайм обновлением
- 📊 Профиль пользователя со статистикой
- 🎯 Система достижений и виртуальных монет
- 🔔 Push-уведомления о запуске бомбы
- 🎭 Опциональное размытие лиц
- 🗺️ Гео-фильтры (10 км / город / страна / глобал)
- 📈 Система стриков (ежедневные бонусы)
- 💎 PRO-версия (UI готов, интеграция платежей - TODO)
- 🎨 Темная тема Material Design 3
- 🔐 Анонимный режим по умолчанию
- ⚡ C++ оптимизации для компрессии медиа
- 🌐 Firebase интеграция (Firestore, Storage, Messaging, Analytics)
- 📱 Поддержка Android 7.0 - 14 (API 24-34)

### Технический стек
- Kotlin 1.9.20
- Jetpack Compose
- Material Design 3
- CameraX для камеры
- Media3 для видео
- Firebase (Firestore, Storage, FCM, Analytics)
- Coil для изображений
- C++ NDK для оптимизаций
- Coroutines для асинхронности

### Известные ограничения
- ⚠️ CameraX реализована только выбором из галереи (live камера - TODO)
- ⚠️ Блюр лиц реализован нативно (ML Kit для автоопределения - TODO)
- ⚠️ PRO подписка UI готов, но нет интеграции с Google Play Billing
- ⚠️ Нет чатов между пользователями
- ⚠️ Нет AR-фильтров и стикеров
- ⚠️ Только русский язык (локализация - TODO)

### Что нужно настроить
1. Firebase проект и `google-services.json`
2. Firebase Rules для Firestore и Storage
3. Cloud Functions для автоматического запуска бомб
4. Иконки приложения (сейчас векторные placeholder)
5. FCM Server Key для пушей

## Формат версионирования

- **Major.Minor.Patch** (например, 1.0.0)
- **Major** - большие изменения, breaking changes
- **Minor** - новые функции, обратно совместимые
- **Patch** - исправления багов
