## 🔥 Топ-3 вопроса

### 1. Как изменить цвета?

```kotlin
// app/src/main/java/com/bombaday/app/ui/theme/Color.kt

val Primary = Color(0xFFFF6B35)  // Оранжевый → измените на свой
val Accent = Color(0xFFFFD23F)   // Жёлтый → измените на свой
```

**Подробнее:** [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md) → раздел "Дизайн"

### 2. Как изменить время окна?

```kotlin
// app/src/main/java/com/bombaday/app/util/Constants.kt

const val CAPTURE_WINDOW_SECONDS = 60  // Измените на 30, 90, 120...
const val VOTING_WINDOW_MINUTES = 5    // Измените на 3, 10, 15...
```

**Подробнее:** [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md) → раздел "Константы"

### 3. Как настроить Firebase?

```bash
# 1. Создайте проект на https://console.firebase.google.com/
# 2. Добавьте Android app (package: com.bombaday.app)
# 3. Скачайте google-services.json
# 4. Замените app/google-services.json.example → app/google-services.json
```

**Подробнее:** [README.md](README.md) → раздел "Firebase Setup"

## 🛠️ Технологии (кратко)

- **Язык:** Kotlin 1.9.20
- **UI:** Jetpack Compose + Material 3
- **Backend:** Firebase (Firestore, Storage, FCM)
- **Камера:** CameraX
- **Видео:** Media3
- **Оптимизация:** C++ NDK
- **Min Android:** 7.0 (API 24)
- **Target Android:** 14 (API 34)

## 🆘 Частые проблемы

### Проблема: "google-services.json not found"
```bash
# Решение:
# 1. Создайте Firebase проект
# 2. Скачайте google-services.json
# 3. Положите в app/google-services.json
```

### Проблема: "Firebase initialization failed"
```bash
# Решение:
# 1. Проверьте что package name = com.bombaday.app
# 2. File → Sync Project with Gradle Files
```

### Проблема: "Build failed"
```bash
# Решение:
# 1. Build → Clean Project
# 2. Build → Rebuild Project
# 3. Перезапустите Android Studio
```
